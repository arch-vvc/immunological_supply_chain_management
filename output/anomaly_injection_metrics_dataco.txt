STAGE 3b — ANOMALY DETECTION BENCHMARK (SYNTHETIC INJECTION)
============================================================

Methodology: independent ground truth via synthetic anomaly
injection (contamination rate ~2%), following standard practice
for evaluating unlabeled anomaly detectors (e.g. Emmott et al. 2013).
This replaces the earlier self-referential pseudo-GT evaluation,
which scored z-score-derived signals against a stricter threshold
of themselves and produced a circular, near-zero-precision result.

Base transactions        : 180,519
Synthetic anomalies added: 7,590 (4.19% of 181,339 rows)
  A. Volume spike          — quantity inflated 8-20x
  B. Frequency burst       — clustered extra transactions on a pair
  C. Concentration shift   — retailer supply forced through one distributor

Method                          Precision   Recall       F1
----------------------------------------------------------
Z-score only  (2+ signals)          0.220    0.089    0.127
Isolation Forest alone              0.532    0.635    0.579
Ensemble (2+ incl. IF)              0.430    0.532    0.476

Diagnostic — signals per injected anomaly:
  0 z-signals : 2204 (29.0%)
  1 z-signals : 4707 (62.0%)
  2 z-signals : 665 (8.8%)
  3 z-signals : 14 (0.2%)
  91.1% of injected anomalies trip <=1 z-signal.
Per-signal recall:
  Volume          : 14.8%
  Frequency       : 11.2%
  Temporal surge  : 4.3%
  Concentration   : 49.8%
  IsolationForest : 63.5%

Best method by F1: Isolation Forest alone (F1=0.579).
Finding: most injected anomalies are single-dimension, so the 2+
z-score rule has near-zero recall and Isolation Forest carries
detection. The '2+ incl. IF' ensemble is STRICTER than IF alone
(needs IF AND a z-signal), trading recall for a little precision —
on F1 it does not beat Isolation Forest by itself. If recall is the
priority, use IF alone (or 'IF OR 2+ z-signals') as the decision rule.

Caveat: the base dataset is not guaranteed anomaly-free (the ARCOS
generator plants its own organic anomalies). Detector hits on those
rows are counted as false positives here, so the precision figures
are a LOWER BOUND on true precision. Recall against the injected
labels is unaffected.
